Sum up 17 November's world news in one image: a pure Python 3.13 standard-library program that draws a newspaper-style front-page infographic (1024x1024 PNG) of Tuesday 17 November 2026 — the Kerch Bridge falling, Iran's drone attack on a US radar in Bahrain, Trump landing in Manila for ASEAN, the ULA Vulcan failure, Nvidia's first post-Huang earnings, the JPMorgan outage and the Pentagon's ninth failed audit — with a hand-built 5x7 bitmap font, vector shapes and a minimal PNG encoder. No network, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
